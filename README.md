# Minigame 1
## Devlog

A great way to understand the relationship between components, gameobjects, and scenes is that they are a trilogy. To understand the next, you should at least know or understand the last. The next part is usually built on information that is given from the last. In this case, gameobjects are built on components and scenes are built on gameobjects. For scenes to be built as a whole, you should know about gameobjects AND components. Thus, the trilogy is completed.
